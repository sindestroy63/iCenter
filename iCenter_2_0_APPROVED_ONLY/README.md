# iCenter 2.0 — Approved Reference Pack (Master v2)

1. `MANIFEST.md` — **главная подробная спецификация**: визуальный контракт, бизнес-правила, каждая публичная страница и каждый раздел Control Panel, проверки и связи.
2. `references/` — 12 отобранных PNG. Некоторые элементы PNG устарели, и для ряда страниц финального PNG нет: следуйте манифесту.
3. `references/INDEX.md` — индекс соответствия изображений экранам.
4. `CLAUDE_CODE_START.md` — инструкция для Claude Code.

Поместить папку `iCenter_2_0_APPROVED_ONLY` в корень репозитория `icenter`. **Не добавлять предыдущий архив с промежуточными генерациями.** Claude Code сначала читает манифест и проверяет код, затем реализует по страницам. Все скриншоты являются дизайн-концептами, не доказательством реализованного функционала.
